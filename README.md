# Computer Engineering Portfolio

A responsive HTML/CSS/JavaScript portfolio website.

## Run locally

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser (or use VS Code Live Server).

## Customize before publishing

- Replace text in `index.html` with your final wording.
- Put your resume PDF in this folder and name it `resume.pdf` (or update both links).
- Add your email and LinkedIn links in the Contact section.
- Add project photos, repositories, and details as your work develops.
- Verify your GitHub profile URL and project repository URL.

## Publish with GitHub Pages

1. Create a public GitHub repository, e.g. `engineering-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and `resume.pdf` (when ready) to its root.
3. In the repository, go to Settings → Pages.
4. Select Deploy from a branch → `main` → `/ (root)` and save.
5. Wait for GitHub to provide the public website URL.

No build tools or dependencies are required.
